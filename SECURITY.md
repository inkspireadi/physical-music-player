# Security policy

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use the repository's private GitHub Security Advisory form and include:

- the affected version or commit;
- reproduction steps;
- the expected security impact;
- any suggested mitigation.

Maintainers should acknowledge a complete report within seven days. Timing for a fix and disclosure will depend on severity and complexity.

Never include YouTube cookies, OAuth tokens, API keys, signing identities, or personal data in a report or reproduction repository.
